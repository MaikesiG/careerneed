# Careerneed v0.1 Product Requirements

## Problem

Technical job seekers repeatedly browse fragmented sources and struggle to connect job requirements with a realistic, evidence-based development path.

## Brand

Project name: Careerneed
Local dev folder: careerneed
GitHub repository: careerneed

## MVP user

A single technical job seeker: the project owner.

## User story

As a technical job seeker targeting Platform, Developer Productivity, SRE-adjacent, and AI Infrastructure roles, I want a daily shortlist of new, deduplicated relevant jobs so I can spend time applying and building evidence instead of repeatedly browsing job boards.

## In scope

- Company watchlist
- Public ATS job ingestion
- Unified job records
- Deduplication
- Job status tracking
- Rules-based job match scoring
- Daily notification

## Out of scope

- Automated job applications
- Scraping authenticated LinkedIn or Indeed pages
- Multi-user billing
- RAG and agents before reliable job ingestion exists
